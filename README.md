# Skin Disease Detection Using CNN

## About
An image classification project using a Convolutional Neural Network (CNN).

## Features
- Upload a skin image.
- Predict its dataset category.
- Display model confidence.
- View results through a Streamlit web app.

## Dataset
Skin Disease Dataset from Kaggle.

## Model
- CNN
- Image size: 128 x 128
- Training: 70%
- Validation: 10%
- Testing: 20%
- Epochs: 10

## Run the app
Install dependencies:

pip install -r requirements.txt

Start Streamlit:

streamlit run app.py

## Disclaimer
This project is for educational purposes only.
It is not a medical diagnostic tool.
